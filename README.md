# xdx

An isometric open-world game built with Buildpad (Three.js / WebGL, no build step).

- `game.json` — title, start items, day length, community settings
- `world/world.json` — seed, spawn, towns, paths, signs, hand-placed tiles
- `world/npcs.json` — characters and their dialogue
- `world/creatures.json` — creature species
- `scenarios/*.json` — quests and story (JSON scenario steps)
- `engine/` — the engine itself

Players can press **B** in the game to build and publish to the shared world.
